MicroIntern 🚀

MicroIntern is a frontend web platform that connects students with local businesses for small, short-term tasks and projects.
💡 Features
- Explore micro-tasks and opportunities
- Helps students gain practical experience
- Helps businesses find students for small tasks
- Simple and user-friendly interface
🛠️ Technologies
- HTML
- CSS
🔮 Future Scope
- User login & profiles
- Task posting and applications
- Payments
- Ratings & reviews
- Backend and database integration

MicroIntern — Small Tasks, Real Experience.
